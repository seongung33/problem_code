1. 논리와 증명 12번  

대우: n은 3의 배수가 아니면 n^2이 3의 배수가 아니다.  

증명: 
어떤 정수 k에 대하여 3k + 1 과 3k+2 는 3의 배수가 아니다.  
n = 3k + 1, 3k+2 이라 할 때 
n^2 = 9k^2 + 6k + 1, 9k^2 + 12k + 2  
9k^2 + 6k + 1 에서 9k^2은 3k(3k) 으로 3의 배수 이다.  
6k = 2(3k) 으로 3의 배수이다. 즉 3(3k^2+ 2k)  + 1 이다. 
3k^2+ 2k = p 라고 두면 3p + 1 로 3의 배수가 아니다.  

9k^2 + 12k + 2  또한 마찬가지로 
3(3k^2 + 4) + 2. 3k^2 + 4 = p 라 두면 
3p+ 2 로 3의 배수가 아니다.  
따라서 n^2은 3의 배수가 아니다. 대우가 성립하므로 

**n^2이 3의 배수면 n은 3의 배수이다.**
