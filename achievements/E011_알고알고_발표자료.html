1. 문제 정의

Task

입력은 이미지와 질문, 그리고 a/b/c/d 4개의 선택지입니다. 모델은 이미지를 보고 질문에 맞는 정답을 단 하나의 소문자 알파벳으로 출력해야 합니다.

  • 이미지 내 객체의 종류, 개수, 재질, 위치를 함께 판단
  • 설명 생성이 아니라 객관식 분류
  • 출력 포맷 오류가 생기면 정답이어도 평가에서 손해

데이터 형태

id,path,question,a,b,c,d,answer
  • train.csv 기반으로 학습
  • 학습 원본 데이터는 5073개
  • 테스트 데이터는 5074개

2. 모델 선택과 핵심 설정

Base Model

Qwen/Qwen3-VL-32B-Instruct를 사용했습니다. 파라미터를 키우는 게 확실하고 리스크가 적은 방법으로 판단해 32B 모델을 채택했습니다.

메모리 최적화

32B 모델을 학습하기 위해 4bit 양자화를 적용했습니다. 설정은 NF4, double quant, bfloat16 compute dtype입니다.

PEFT

전체 파라미터를 다 학습하지 않고, LoRA로 주요 projection 레이어만 효율적으로 조정했습니다.

MODEL_ID = "Qwen/Qwen3-VL-32B-Instruct" bnb_config = BitsAndBytesConfig( load_in_4bit=True, bnb_4bit_use_double_quant=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.bfloat16, ) lora_config = LoraConfig( r=64, lora_alpha=128, lora_dropout=0.05, bias="none", target_modules=["q_proj","k_proj","v_proj","o_proj","gate_proj","up_proj","down_proj"], task_type="CAUSAL_LM", )

3. 프롬프트 설계

시스템 지시문

모델이 설명을 장황하게 생성하지 않도록, "a, b, c, d 중 하나만 출력"하도록 강하게 제약했습니다.

  • 정답 알파벳 편향 방지 문구 포함
  • 불필요한 설명, 구두점, 추가 텍스트 금지
  • 출력 파싱 안정성 향상
  • 영어로 작성

유저 프롬프트

test.csv와 같은 언어인 한국어로 이미지 관찰을 요구하고, 질문과 선택지를 구조화해서 넣었습니다. 특히 객체 종류·개수·재질을 꼼꼼히 보라고 유도합니다.

"주어진 사진을 꼼꼼하게 관찰하고..." "질문: {question}" "선택지: a, b, c, d" "가장 적절한 정답의 알파벳 소문자만 출력"

5. 전체 학습 파이프라인

Step 1

Qwen3-VL-32B 로드 + 4bit 양자화 + gradient checkpointing

Step 2

LoRA 적용 후 trainable parameter만 효율 학습

Step 3

희소 정답 업샘플링 및 선지 셔플링, 이미지 증강

Step 4

8bit AdamW + cosine scheduler로 학습 진행

Step 5

adapter와 processor 저장 후 zip 압축 및 백업

Step 6

최종 검증 및 성능 측정 (테스트셋 전체 추론)

6. 추론 전략

TTA 적용

테스트 시 원본 이미지 + 좌우반전 이미지를 각각 넣어 두 번 추론했습니다. 단일 시점 판단보다 안정적인 선택을 기대할 수 있습니다.

  • 원본 이미지 로짓 계산
  • 좌우반전 이미지 로짓 계산
  • 두 결과를 결합해 최종 답 선택

로짓 기반 선택

생성된 텍스트를 파싱하는 대신, 마지막 토큰의 로짓 중 a, b, c, d 토큰만 추출해 비교했습니다.

target_choices = ['a', 'b', 'c', 'd'] target_ids = [tokenizer.encode(c, add_special_tokens=False)[0] for c in target_choices] choice_logits = outputs.logits[0, -1, target_ids]
이 방식은 출력 문장 파싱 오류를 줄이고, 객관식 문제에 더 직접적인 판별 구조를 제공한다는 장점이 있습니다.
