# Problem Code

알고리즘 문제 풀이, 수업 과제, 스터디 연습 코드를 모아두는 학습 기록 저장소입니다.

주로 Python으로 풀이 과정을 정리하고 있으며, SWEA/BOJ 유형 문제, 자료구조와 알고리즘 연습, AI 및 HTML/CSS 과제 파일도 함께 보관하고 있습니다.

## What I Practice

- 자료구조: stack, queue, heap, linked list, tree, graph
- 알고리즘: binary search, DFS/BFS, backtracking, greedy, dynamic programming, shortest path, MST, simulation
- 구현 연습: 입력 처리, 예외 케이스 점검, 시간 복잡도 개선
- 학습 과제: AI 실습 노트북, HTML/CSS 기초 과제

## How to Run

Python 풀이 파일은 대부분 표준 입력을 기준으로 작성되어 있습니다.

```bash
python path/to/solution.py
```

입력 파일이 필요한 경우 같은 폴더의 `sample_input.txt` 또는 문제에서 제공한 입력을 사용합니다.

## Notes

- 문제 풀이 과정에서 작성한 코드라 파일별 스타일이나 주석 밀도는 다를 수 있습니다.
- 일부 파일명은 문제명, 수업명, 연습 목적에 맞춰 작성되어 있습니다.
- 더 나은 풀이를 찾거나 복습하면서 코드를 계속 정리해 나갈 예정입니다.
